# Fix-Welle 2 – Regression aus dem Re-Review (Commit `eba8282`)

an einer Stelle **nicht** ankam: `purgeBaseDir()` prüfte den Basisordner selbst nicht auf
Symlinks. Das ist eine **selbst eingeführte Regression**, keine übersehene Vorbedingung –
Befund 1 der Fix-Welle 1 (own()/writeIndex()/makeDirectories() lehnen Symlinks ab) hätte
konsequent auch `purgeBaseDir()` erfassen müssen. Zusätzlich zwei kleinere Befunde.
